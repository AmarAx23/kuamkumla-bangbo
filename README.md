# ระบบควบคุมการลา งานป้องกันปราบปราม สภ.บางบ่อ

เว็บคุมการลาของเจ้าหน้าที่ ใช้ **Google Sheets เป็นฐานข้อมูล** (คอลัมน์เดิม: ลำดับ | ชื่อ | วันที่ลา | เดือน | ชุดปฏิบัติการที่ | ปีงบประมาณ | การดำเนินการ | หมายเหตุ) และเปิดหน้าเว็บผ่าน **GitHub Pages**

**ความสามารถ**
- ภาพรวม: ใครลาวันนี้, ลาใน 14 วันข้างหน้า, รายการรออนุมัติ
- ปฏิทินรายเดือน กรองตามชุดปฏิบัติการ
- รายการลา ค้นหา/กรอง/เรียงลำดับ และส่งออก CSV (เปิดด้วย Excel ได้)
- สรุปจำนวนครั้งและจำนวนวันลารายบุคคลในปีงบประมาณ
- ยื่นใบลา (สถานะเริ่มต้น "รออนุมัติ") พร้อมเตือนถ้าชุดเดียวกันมีคนลาช่วงเดียวกัน
- โหมดผู้อนุมัติ (ใส่รหัส): อนุมัติ / ไม่อนุมัติ / แก้ไข / ลบ
- วันลาคงเหลือรายบุคคลตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยการลาของข้าราชการ พ.ศ. 2555: ลาพักผ่อน 10 วันทำการ/ปี แยก "ประจำปี" กับ "สะสม" (รวมไม่เกิน 20 วัน หรือ 30 วันถ้ารับราชการ 10 ปีขึ้นไป, ไม่มีสิทธิ์ถ้ารับราชการไม่ครบ 6 เดือน), ลากิจ 45 วัน (ปีแรก 15), ลาป่วย 60 วัน, ลาคลอด 90 วันปฏิทิน, ลาช่วยภริยาคลอด 15 วันทำการ — ผู้อนุมัติกรอกวันสะสมยกมาและวันเริ่มรับราชการรายคนได้ (แท็บ "สิทธิ์ลา") และกำหนดปีงบฯ ที่เริ่มนับใหม่ได้
- วันหยุดราชการในปฏิทิน และเลือกนับวันลาแบบวันปฏิทินหรือวันทำการ (หน้า "ตั้งค่า" ของผู้อนุมัติ เก็บในแท็บ "ตั้งค่าระบบ" และ "วันหยุด")
- เพดานการลาพร้อมกันต่อชุด: ตั้งในหน้าตั้งค่า วันที่เกินขึ้นกรอบแดงในปฏิทิน ฟอร์มยื่นลาเตือน และหน้าภาพรวมแสดงวันที่เกินใน 60 วันข้างหน้า
- พิมพ์ใบลาแบบราชการ (แบบใบลาพักผ่อน / แบบใบลาป่วย ลาคลอดบุตร ลากิจส่วนตัว) พร้อมสถิติการลาในปีงบฯ จากปุ่ม "พิมพ์ใบลา" ในหน้ารายการลา
- หน้าตรวจข้อมูล (ผู้อนุมัติ): ปีงบฯ ไม่ตรงเดือน, ไม่มีปีงบฯ, รายการซ้ำ, ไม่ระบุชุด/ประเภท, วันที่อ่านไม่ได้ พร้อมปุ่มแก้ลงชีต
- กราฟสรุป: วันลารายเดือน / แยกตามชุด / แยกตามประเภท เทียบปีงบฯ และพิมพ์เป็น PDF ได้
- อ่านข้อมูลเก่าในชีตได้ทันที รวมถึงแบบข้ามเดือน เช่น วันที่ลา `28-2` + หมายเหตุ `28 ก.ค.- 2 ส.ค.`

```
leave-system/
├── index.html          ← หน้าเว็บ (ขึ้น GitHub Pages)
├── logo.png            ← ตรา สภ.บางบ่อ (หัวเว็บ + ไอคอนแท็บ)
└── apps-script/Code.gs ← โค้ดฝั่ง Google Sheets
```

---

## ขั้นที่ 1 — ติดตั้ง Apps Script ใน Google Sheet

1. เปิด Google Sheet คุมลา → เมนู **ส่วนขยาย › Apps Script**
2. ลบโค้ดเดิม แล้ววางเนื้อหาไฟล์ `apps-script/Code.gs` ทั้งหมด
3. **เปลี่ยนรหัสผู้อนุมัติ** ที่บรรทัด `const ADMIN_PIN = '1234';`
4. กด **บันทึก** → **การทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. กดทำให้ใช้งานได้ → อนุญาตสิทธิ์ → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

> ถ้าแก้ Code.gs ภายหลัง ต้องไปที่ **จัดการการทำให้ใช้งานได้ › แก้ไข › เวอร์ชัน: ใหม่** URL จะยังเหมือนเดิม

## ขั้นที่ 2 — ใส่ URL ในหน้าเว็บ

เปิด `index.html` แก้บรรทัดนี้ (อยู่ช่วงต้นไฟล์):

```js
const API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

(ถ้าเว้นว่างไว้ เว็บจะเปิดในโหมดตัวอย่าง ใช้ข้อมูลสมมติ รหัสผู้อนุมัติคือ 1234)

## ขั้นที่ 3 — ขึ้น GitHub Pages

1. สร้าง repository ใหม่ใน GitHub เช่น `leave-system`
2. อัปโหลด `index.html`, `logo.png` (และโฟลเดอร์ `apps-script` ถ้าต้องการเก็บไว้)
   - ผ่านเว็บ: **Add file › Upload files** แล้วลากไฟล์ใส่ → Commit
   - หรือผ่านคำสั่ง:
     ```bash
     git init && git add . && git commit -m "ระบบคุมลา"
     git branch -M main
     git remote add origin https://github.com/<ชื่อผู้ใช้>/leave-system.git
     git push -u origin main
     ```
3. ไปที่ **Settings › Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/leave-system/`

## หมายเหตุการใช้งาน

- **แต่ละปีงบประมาณ = 1 แท็บ** ชื่อเป็นตัวเลขปี เช่น `2569`, `2570` ถ้ายื่นลาในปีงบฯ ที่ยังไม่มีแท็บ ระบบจะสร้างให้อัตโนมัติโดยคัดลอกจากแท็บ `ต้นฉบับ`
- ระบบเขียนลงแถวว่างแถวแรก (ที่พิมพ์เลขลำดับรอไว้) การลบจะล้างข้อมูลในแถวแต่คงเลขลำดับไว้
- ยังแก้ข้อมูลในชีตโดยตรงได้ตามปกติ เว็บจะอ่านค่าล่าสุดทุกครั้งที่โหลด
- จำนวนวันลานับแบบ **วันปฏิทิน** (รวมเสาร์-อาทิตย์และวันหยุด)
- สถานะที่ใช้: `รออนุมัติ` `อนุมัติ` `ไม่อนุมัติ` `ยกเลิก` (ช่องว่างแสดงเป็น "ไม่ระบุ")

## ความปลอดภัย

- หน้าเว็บ GitHub Pages และ Apps Script ที่ตั้ง "ทุกคน" **ใครมีลิงก์ก็ดูรายชื่อและวันลาได้** อย่าเผยแพร่ลิงก์นอกหน่วย
- ใครมีลิงก์ก็ยื่นใบลาได้ แต่อนุมัติ/แก้ไข/ลบต้องใช้รหัส ซึ่งเก็บอยู่ใน Apps Script (ไม่อยู่ใน GitHub)
- ถ้า repository เป็น public โค้ดหน้าเว็บจะเปิดดูได้ แต่ไม่มีข้อมูลการลาอยู่ในโค้ด
